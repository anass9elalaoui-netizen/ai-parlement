# DIRAM - نظام تحليل الأخبار الدبلوماسية للمغرب
## نتائج إعادة تنظيم المشروع / Project Reorganization Results

![DIRAM Logo](https://via.placeholder.com/200x100/c73e1d/ffffff?text=DIRAM)

### 📋 ملخص المشروع / Project Summary

**DIRAM** (Diplomatic Intelligence & Relations Analyzer for Morocco) هو نظام شامل لتحليل الأخبار الدبلوماسية وجمع المعلومات الاستخباراتية المتعلقة بالمغرب من مصادر إعلامية دولية متعددة.

## ✅ التحسينات المنجزة / Completed Improvements

### 🎯 1. إعادة هيكلة خدمات Backend
**✅ مكتمل بنجاح / Successfully Completed**

#### 📁 الهيكل الجديد:
```
backend/services/
├── ai/                    # خدمات الذكاء الاصطناعي
│   ├── sentiment.py       # تحليل المشاعر 
│   ├── summarizer.py      # تلخيص النصوص
│   ├── ner.py            # استخراج الكيانات المسماة
│   └── tone.py           # تحليل النبرة الدبلوماسية
├── alert/                 # خدمات التنبيهات
│   └── trigger.py        # إنشاء التنبيهات التلقائية
├── auth/                  # خدمات المصادقة
│   └── jwt_handler.py    # إدارة JWT وأذونات المستخدمين
└── ingestion/            # خدمات الاستيعاب
    └── article_saver.py  # حفظ المقالات ومعالجتها
```

#### 🔧 الخدمات المطورة:
- **NER Service**: استخراج الكيانات المسماة مع التركيز على المغرب
- **Tone Service**: تحليل النبرة الدبلوماسية والموقف
- **Alert Service**: نظام تنبيهات متقدم بمستويات أولوية متعددة
- **JWT Handler**: مصادقة آمنة مع إدارة الأدوار والأذونات
- **Article Saver**: معالجة المقالات مع خط أنابيب AI متكامل

### 🗄️ 4. تحسين قاعدة البيانات - 4 جداول أساسية
**✅ مكتمل بنجاح / Successfully Completed**

#### 📊 الجداول الأساسية:
```sql
1. User (المستخدمون)
   - المصادقة والتصريح
   - الأدوار والأقسام
   - تفضيلات المستخدم

2. Article (المقالات)
   - محتوى المقالات المجمعة
   - بيانات المصدر والتاريخ
   - درجات الصلة والمعالجة

3. AnalysisResult (نتائج التحليل)
   - تحليل المشاعر والنبرة
   - استخراج الكيانات
   - تقييم المخاطر والتصنيف

4. Alert (التنبيهات)
   - تنبيهات دبلوماسية تلقائية
   - مستويات الأولوية والفئات
   - سير العمل والتصعيد
```

#### 🔧 المميزات:
- **أداء محسن**: فهارس مركبة للاستعلامات السريعة
- **تصنيف شامل**: Enums للأدوار، الأقسام، الأولويات، الفئات
- **علاقات واضحة**: ربط واضح بين الجداول
- **بيانات وصفية غنية**: معلومات تفصيلية لكل جدول

## 🔧 التقنيات المستخدمة / Technologies Used

### Backend
- **Python 3.11+**: لغة البرمجة الأساسية
- **FastAPI**: إطار عمل API السريع
- **SQLAlchemy**: ORM قاعدة البيانات
- **OpenRouter**: خدمات الذكاء الاصطناعي
- **JWT**: مصادقة آمنة

### Frontend
- **Blazor Server**: إطار عمل الواجهة
- **C# .NET**: لغة البرمجة
- **Bootstrap**: تصميم responsive
- **JavaScript**: تفاعلات العميل

### AI & ML
- **LLM Models**: نماذج اللغة الكبيرة
- **NLP Processing**: معالجة اللغات الطبيعية
- **Sentiment Analysis**: تحليل المشاعر
- **Entity Recognition**: استخراج الكيانات

### Database
- **PostgreSQL/SQLite**: قواعد البيانات المدعومة
- **Alembic**: إدارة schema migrations
- **Connection Pooling**: تجمع الاتصالات
